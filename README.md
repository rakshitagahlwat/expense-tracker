# 💸 Personal Expense Tracker

A modern and animated Personal Expense Tracker built using HTML, CSS, and JavaScript.

## ✨ Features

- Add Income & Expenses
- Live Balance Calculation
- Beautiful Glassmorphism UI
- Smooth Animations
- Responsive Design
- Local Storage Support
- Delete Individual Transactions
- Clear All Transactions
- Mobile Friendly
